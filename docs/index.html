Agenda de eventos gratuitos de Buenos Aires

App Android para descubrir eventos gratuitos y culturales de CABA, con su feed de datos abierto. Sin API key, sin registro, sin costo.

Descargar la app

APK del último build. Android 7.0 o superior. Al instalarlo, el teléfono va a pedir permitir "fuentes desconocidas": es lo normal fuera de Play Store.

Modalidad de ingreso

  • INGRESO_LIBRE — se entra sin trámite previo
  • ORDEN_DE_LLEGADA — sujeto al aforo de la sala
  • RESERVA_PREVIA — requiere reserva digital

Cómo se mantiene

Un script de Python corre en GitHub Actions cada mañana, normaliza las agendas oficiales y commitea docs/events.json. GitHub Pages lo sirve por HTTPS con CDN. La app Android lo descarga una vez al día y lo cachea en Room para funcionar sin conexión.
